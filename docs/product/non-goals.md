# Non-Goals (O que o Vocentro NÃO é)

Para prevenir desvio de escopo (*scope creep*) e manter todas as evoluções perfeitamente alinhadas com a nossa proposta de valor, definimos explicitamente os **Não-Objetivos** da plataforma:

1. **Não é um ATS (Applicant Tracking System) para empresas**: O Vocentro é uma plataforma *candidate-first* focada em empoderar o profissional, e não um sistema corporativo de gestão de vagas para RHs.
2. **Não é uma rede social profissional**: Não temos feed social, publicações, curtidas ou sistema de conexão entre pares (estilo LinkedIn).
3. **Não substitui o recrutador nem garante contratação**: A plataforma instrumentaliza o candidato com IA e dados, mas a decisão de entrevista e contratação pertence soberanamente às empresas contratantes.
4. **Não utiliza IA para tomada de decisão discriminatória ou automatizada de rejeição**: A IA do Vocentro atua exclusivamente como copiloto consultivo e explicativo para o candidato.
5. **Não é um banco de currículos para venda de leads**: Os dados do usuário são protegidos via RLS e pertencem exclusivamente ao candidato.
